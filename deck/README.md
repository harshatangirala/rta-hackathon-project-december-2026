# Slide deck source

Seventeen slides, one HTML file per slide in `slides/`, shared styling in `deck.css`, order and typefaces in `deck.json`. Speaker notes are in the `<aside>` element at the end of each slide file.

The deck was built as an editable slide deck (1920 x 1080 per slide). To present it, open the slides in a Slides-compatible editor or render each `slides/*.html` file in a browser together with `deck.css`. A PDF or PowerPoint file can be exported from the editor; none is stored here.

Slide order: cover, problem, data, headline, architecture, forecast-design, forecast-results, models, capacity, swap, congestion, agents, agent-card, dashboards, recommendations, limits, next.
