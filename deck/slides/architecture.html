The Flow is organised in seven colour-coded zones. Raw data is cleaned once and aggregated once, then used twice. The forecast branch is validated on its own and ends in forecast_metrics. The decision branch uses observed demand, running times and fleet capacity, and feeds the AI agents and the control-room webapp. Be honest if asked: the forecast does not yet feed the decision recipe; wiring it in as an early warning is the next step. Python is used only in five places: forecast metrics, the decision engine and swap, segment geometry, the agent case file and the answer checker.
