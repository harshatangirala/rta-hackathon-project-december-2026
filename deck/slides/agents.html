What the check proves, and what it does not

It proves every number comes from the data and no fare rise, trip cut, bus lane or skipped driver rest is suggested. It does not prove the reasoning is wise, so two human confirmations stay mandatory.

The language model never calculates. It receives a short fact sheet built by a Python recipe, written by the Flow. Two specialist roles and a coordinator run as Prompt recipes through Dataiku’s LLM Mesh. A second Python recipe checks every answer, and the webapp shows a card as AI-written, numbers verified only when both of its answers pass; otherwise it falls back to the rule-based suggestion. Next step: move to native Dataiku Agents with read-only dataset tools, keeping the checker in front.
