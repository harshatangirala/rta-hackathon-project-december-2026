DASHBOARDS

Two webapps, built to prevent human error

DemandPulse Ops · live control room

  • Map and hotspots: replay the day hour by hour
  • Actions and agents: 16 actions, two human ticks each, 12 checked AI cards, end-of-day report
  • Supply-demand gaps: a 24-hour strip for any route
  • Passenger advisory: a calmer nearby hour
  • Forecast and method: model vs baseline

DemandPulse Team7 · planning snapshot

  • Forecast accuracy by horizon and metric
  • Sortable route explorer
  • Swap scenario: 18 swaps, 13 of 28 fixed
  • Three decision cards
  • Agent and data-handling notes

Every number is read from a Dataiku dataset. Approve unlocks only after two named checks, such as “spare bus and rested driver available”. If the backend fails, the page says so instead of showing wrong data.

DemandPulse Ops reads nine Flow datasets and the two agent datasets live through a Python backend, so nothing is retyped. DemandPulse Team7 is a snapshot of the outputs as of 17 Nov 2026 for planners. The passenger advisory is a message aid for RTA staff, not a public trip planner, because the guide asks teams not to build consumer apps.
